Racha Conta

Política de Privacidade

Resumo: O Racha Conta respeita sua privacidade. Coletamos apenas os dados necessários para o funcionamento do app e nunca vendemos suas informações.

1. Introdução

Esta Política de Privacidade descreve como o aplicativo Racha Conta, desenvolvido por Antunes Tech, coleta, usa e protege as informações dos usuários.

Ao utilizar o aplicativo, você concorda com as práticas descritas nesta política.

2. Dados Coletados

2.1 Dados de Conta (opcional)

Se você optar por criar uma conta, coletamos:

  • E-mail: Para autenticação e recuperação de senha
  • Senha: Armazenada de forma criptografada

2.2 Dados de Uso do App

Para funcionalidade do aplicativo, armazenamos:

  • Histórico de contas divididas (estabelecimento, valores, pessoas)
  • Preferências do usuário (tema claro/escuro)

2.3 Modo Offline

O aplicativo pode ser usado sem criar conta. Neste caso, todos os dados são armazenados apenas localmente no seu dispositivo e não são enviados para nossos servidores.

3. Como Usamos os Dados

Utilizamos os dados coletados exclusivamente para:

  • Permitir o funcionamento das funcionalidades do app
  • Sincronizar seu histórico entre dispositivos (se logado)
  • Enviar códigos de recuperação de senha quando solicitado
Importante: Não utilizamos seus dados para publicidade, marketing ou qualquer finalidade comercial. Não vendemos, alugamos ou compartilhamos suas informações com terceiros.

4. Armazenamento e Segurança

Os dados são armazenados de forma segura utilizando:

  • Supabase: Plataforma de banco de dados com criptografia em trânsito e em repouso
  • Autenticação segura: Senhas criptografadas com bcrypt
  • HTTPS: Todas as comunicações são criptografadas

5. Seus Direitos

Você tem direito a:

  • Acessar seus dados pessoais
  • Corrigir informações incorretas
  • Excluir sua conta e todos os dados associados
  • Usar offline sem fornecer dados pessoais

6. Dados de Menores

O Racha Conta não é direcionado a menores de 13 anos. Não coletamos intencionalmente dados de crianças. Se você acredita que coletamos dados de um menor, entre em contato conosco.

7. Alterações nesta Política

Podemos atualizar esta política periodicamente. Alterações significativas serão comunicadas através do aplicativo ou por e-mail (se cadastrado).
